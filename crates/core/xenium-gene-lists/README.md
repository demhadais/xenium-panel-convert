# Xenium Panel Designer Allowed Genes

Only a subset of the human and mouse genomes are supported by the Xenium instrument when designing custom add-on panels. More information about designing gene-lists is available in [10x Genomics' documentation](https://www.10xgenomics.com/support/software/xenium-panel-designer/latest/tutorials/create-gene-list#yesprobe). The gene-lists themselves are available for download at:

- **Xenium v1:** https://cdn.10xgenomics.com/raw/upload/v1721161837/software-support/Xenium-panels/human_and_mouse_2020-A-ref-yesprobe-genes_v1assay.csv
- **Xenium Prime:** https://cdn.10xgenomics.com/raw/upload/v1721161425/software-support/Xenium-panels/human_and_mouse_genes_xenium_prime-yesprobe-genes.csv
